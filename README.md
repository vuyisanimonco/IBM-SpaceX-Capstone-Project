IBM-SpaceX-Capstone-Project

IBM Applied Data Science Capstone Project – SpaceX Falcon 9 Launch Analysis

Introduction
This project is about studying SpaceX Falcon 9 launches. I used data to learn more about the launches and what can affect the success of rocket landings.

Project Goals
The goals of this project were to:

- Collect SpaceX launch data.
- Clean and prepare the data.
- Study the launch data and look for patterns.
- Use SQL to answer questions about the data.
- Create a map showing the launch sites.
- Build a dashboard to show the results.
- Use machine learning to predict landing outcomes.

Tools Used

The tools I used in this project include:

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- SQL
- Folium
- Plotly Dash
- Scikit-learn
- GitHub
What I Did
I collected and cleaned the data before analysing it. I used charts, SQL and maps to understand the launch information. I also created an interactive dashboard and compared four machine-learning models.

Machine-Learning Results

I compared four models:

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbours (KNN)

Logistic Regression was the best model in my comparison. It achieved 71.4% test accuracy and 69.7% balanced accuracy.

Conclusion

This project helped me learn how to use data science tools to study real data. I was able to analyse SpaceX launches, create visualisations and build models to predict landing outcomes.
